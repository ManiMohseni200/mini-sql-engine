# Mini SQL Engine

A lightweight SQL engine built from scratch in Python to explore
lexing, parsing, ASTs, query execution, and database internals.

## Features

- SQL lexical analysis
- SQL parser
- Abstract Syntax Tree (AST)
- SELECT queries
- WHERE conditions
- ORDER BY
- ASC / DESC sorting
- CSV data loading
- Custom SQL error handling
- Interactive CLI

## Example

```sql
SELECT name
FROM students
WHERE age > 20
ORDER BY gpa DESC
```
